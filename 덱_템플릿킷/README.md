# 덱 템플릿킷 — SKU LIKELION 강의덱 재사용 템플릿

BM 수익모델 강의덱(`BM_수익모델_강의덱.html`)에서 **재사용 가능한 부분만 뽑아** 정리한 킷입니다.
새 강의덱을 **같은 느낌**으로 빠르게 만들기 위한 것.

캔버스는 **1280×720 단일 HTML 웹덱**. 방향키로 발표, `F` 전체화면, PDF 버튼으로 인쇄.

---

## 폴더 구조

```
덱_템플릿킷/
├─ README.md                  ← (이 파일) 킷 개요 + 새 덱 만드는 5단계
├─ 00_레이아웃-선택가이드.md    ← 상황 → 어떤 레이아웃 고를지 결정표 ★
├─ styles/
│  └─ deck.css                ← 디자인 시스템 + 전 레이아웃 모듈 (토큰·크롬·엔진 CSS)
├─ starter/
│  └─ deck-template.html      ← 새 덱 시작용 빈 뼈대 (고정1·2·3 + 파트전환 + 본문 슬롯)
├─ layouts/
│  └─ 카탈로그.html            ← 모든 레이아웃 실물 라이브러리 (방향키로 훑어보기) ★
├─ images/
│  └─ 공통이미지프롬프트.md      ← clay v2 3D 이미지 공통 프롬프트 + 네이밍 규칙
└─ guide/
   └─ 디자인시스템.md           ← 색·타이포·공간 규칙
```

★ = 제작할 때 가장 자주 여는 두 파일.

---

## 새 덱 만드는 5단계

1. **스타터 복사** — `starter/deck-template.html`을 새 폴더로 복사하고, 옆에 이미지용 `img/`(그리고 `img/slides/`) 폴더를 둡니다.
   - `styles/deck.css`도 함께 복사하거나, `<link>` 경로를 이 킷의 `deck.css`로 맞춥니다.
   - 스타터·카탈로그는 킷 자체 데모 이미지(`../img/`)를 참조합니다. 새 덱에선 이미지 경로를 자신의 `img/` 로 변경.
2. **고정 1·2·3 채우기** — 표지(주차·제목·발표자), 도입(주제 한 줄), 아젠다(4항목)를 우리 강의로 교체. (디자인은 그대로)
3. **본문 쌓기** — [`00_레이아웃-선택가이드.md`](00_레이아웃-선택가이드.md)에서 상황에 맞는 레이아웃을 고르고, [`layouts/카탈로그.html`](layouts/카탈로그.html)에서 해당 `<section>`을 복사해 "본문 슬롯"에 붙여넣고 내용만 교체.
4. **파트 전환** — 파트 수만큼 `part-divider`를 배치, 진행 도트의 `is-active`를 현재 파트로 이동.
5. **이미지 생성** — 필요한 3D 일러스트는 [`images/공통이미지프롬프트.md`](images/공통이미지프롬프트.md)의 4블록 프롬프트로 만들어 네이밍 규칙대로 `img/slides/`에 저장.

## 배포 (단일 파일)

개발용은 `img/` 참조(가벼움). 학생 배포·오프라인은 **이미지를 base64로 인라인한 단일 HTML**:
- `<img src="img/...">` 와 CSS `url(img/...)` 를 `data:image/...;base64,...` 로 치환.
- 용량이 크면 먼저 이미지를 ≤~900px로 다운스케일 + 압축(pngquant/oxipng) 후 인라인 → 3~8MB 목표.
- Netlify 드래그앤드랍 배포 시 `_redirects` 로 루트를 배포본으로 200 리라이트.

> 원본 파이프라인 상세는 프로젝트 루트 `README.md` 및 각 세션의 `README.md` 참고.

## 설계 원칙 (이 킷이 원본과 다른 점)

- **슬라이드 번호 스코핑 제거**: 원본은 `[data-slide="S07"]`로 레이아웃을 걸었지만, 킷은 **타입 클래스**(`.venn-slide`, `.center-v` 등)로 바꿔 **몇 번째 슬라이드든** 재사용됩니다. `data-slide` 속성은 이제 라벨(선택)일 뿐, 네비게이션은 DOM 순서로 동작.
- **CSS 분리**: 디자인 시스템을 `deck.css` 한 파일로 분리 → 여러 덱이 공유.
- **모디파이어 일반화**: 원본의 슬라이드별 "캔버스 채우기/세로 가운데" 튜닝을 `.canvas-fill` · `.center-v` 재사용 클래스로 정리.
