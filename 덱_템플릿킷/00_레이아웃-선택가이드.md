# 레이아웃 선택 가이드 — 어떤 상황에 어떤 레이아웃?

> 슬라이드를 만들 때 **"내가 지금 무엇을 하려는가(상황)"** 를 먼저 정하고, 아래 표에서 레이아웃을 고릅니다.
> 각 레이아웃의 실물은 [`layouts/카탈로그.html`](layouts/카탈로그.html)을 방향키로 넘겨 보세요. (우하단 회색 라벨 = 붙여넣을 `<section>` 클래스)

---

## 1. 상황 → 레이아웃 결정표

| 지금 하려는 것(상황) | 레이아웃 (class) | 카탈로그 라벨 | 비고 |
|---|---|---|---|
| **표지**를 연다 | `slide cover` | 고정1 | 주차·제목·발표자만 교체 |
| 오늘 **주제를 소개**한다 | `slide s02-slide` | 고정2 | 좌 큰 제목 + 우 3D |
| 오늘 **차례(아젠다)**를 보여준다 | `slide s03-slide` | 고정3 | 우측 번호 리스트 4항목 |
| **파트를 전환**한다(리듬) | `slide part-divider` | 전환 | 진행 도트 `is-active` 이동 |
| **강한 한 문장**을 던진다(문제 제기) | `slide center-msg-a` | center-msg-a | 큰 따옴표 질문 + 콜아웃 |
| **꼭 기억할 질문**을 남긴다 | `slide center-msg-b` | center-msg-b | 서브라벨 + 초대형 질문 |
| 개념을 **글 + 그림**으로 설명(가장 흔함) | `slide center-v` | center-v | 좌 본문 + 우 hero 3D |
| **지난 시간을 리마인드**한다 | `slide remind-slide` | remind-slide | 기울어진 사진 2장 |
| **3요소**를 나란히, 1개 강조 | `slide three-card center-v` | three-card | `.card.focus`로 오늘 주제 |
| **표**로 개념 2~5개를 비교/정리 | `slide tbl canvas-fill` | tbl | 우측 일러스트 거터 자동 |
| 표 아래 **보충 카드 3장** | `+ .note-grid` | tbl(+note) | 표 + 3노트 |
| 표 아래 **태그 나열** | `+ .tag-block` | tbl(+tag) | pill 태그 행 |
| **여러 항목을 빠르게 훑기**(4×2) | `slide card-grid` | card-grid | 8칸 카드 |
| 항목이 **7개 등 비대칭** | `slide card-grid wide-12` | card-grid wide-12 | 12칼럼 스팬 |
| **포함/부분 관계**를 도형으로 | `slide venn-slide` | venn-slide | 동심원 벤 (원본 9p) |
| **두 주체·두 개념 대비** | `slide actor-slide` | actor-slide | 2카드 + 배경 일러스트 |
| **좌우 2개를 정식 비교**(한쪽 추천) | `slide compare-slide` | compare-slide | 한쪽 `.lean-cmp` 강조 |
| **활동/실습 단계**를 안내(2×2) | `slide flow-slide` (+`.flow-steps-2`) | flow-slide | 배경 일러스트 |
| **실습 지시**를 세로로(1~3단계) | `slide flow-slide` (+`.work-steps`) | flow-slide(work) | 큰 번호 스텝 |
| **캔버스/보드**를 통째로(9칸) | `slide lean-slide canvas-fill` | lean-slide | 린캔버스 9칸 |
| **가정 → 위험 → 검증** 흐름 | `slide risk-slide` | risk-slide | 3단 세로 + 화살표 |
| **여러 지표를 카드로** + 공식 | `slide metric-slide canvas-fill` | metric-slide | 5카드 + 비율 공식 |
| **A → B 매핑**(모델→지표 등) | `slide map-slide` | map-slide | 4열 매핑 카드 |
| **방법 2개를 상세 비교** | `slide price-slide` | price-slide | 2 상세 카드 |
| **세션 요약**으로 닫기 | `slide concept-recap` | concept-recap | 배경 이미지 + 4카드 |
| 다크 배경으로 **한 줄 마무리** | `slide closing` | (스타터 참고) | 흰 텍스트 |

## 2. 두 개의 횡단 규칙 (모든 레이아웃 공통)

### ① 색은 문법이다 (color as syntax)
- **파랑(`--cobalt`)** = 강조/핵심/오늘의 대상. 한 슬라이드에서 **키워드 1~2개**만.
- **오렌지·레드** = 문제·오답·경고·주의일 때만. (`.callout.orange`, `.risk-card.warn`, `.lc.key`)
- 한 슬라이드에 **파랑+오렌지+레드를 동시에 강조하지 않는다.** 본문 전체를 파랗게 칠하지 않는다.

### ② 가운데 커넥터 (connector-in-the-middle)
- 두 패널/단계를 이을 땐 **파란 화살표·라인**으로 관계를 만든다: 흐름(→), 대비(≠), 전후(before→after), 가정→검증(↓).
- 예: `venn`(포함 ⊃), `actor`(≠), `risk`(↓), `map`(↓), `compare`(vs).

---

## 3. 리듬 규칙 (덱 전체)

- **같은 레이아웃 3연속 금지.** 설명형(center-v·tbl·card-grid)과 참여형(center-msg·flow·lean)을 번갈아.
- **파트마다 `part-divider`** 로 끊어 진행 위치를 보여준다(진행 도트).
- **제목은 주제명이 아니라 결론.** "수익 모델" (X) → "수익 모델은 발명이 아니라 선택과 조합" (O).
- **본문 5줄 초과 → 슬라이드 분할.**
- 활동 슬라이드에는 `.timing`(예: `선정 3분`) 배지로 타임박스 표시.

## 4. 추천 시퀀스 (강의형 예)

```
표지 → 도입 → 아젠다
 └ part1 전환 → center-msg-a(문제제기) → center-v/remind/three-card
 └ part2 전환 → venn(개념구분) → tbl(비교) → tbl(사례)
 └ part3 전환 → center-v(개관) → card-grid×2(나열) → reverse(워밍업) → actor → tbl(기준) → center-msg-b(핵심질문)
 └ part4 전환 → flow(개관) → compare → flow(실습) → lean(9칸) → risk → metric → map
 → concept-recap(요약)
```

> 참고: 30종 추상 레이아웃 라이브러리(L01~L30)의 원본은 프로젝트 루트 `ppt_layout_reference.md`. 이 가이드는 그중 **덱에서 실제로 구현된 레이아웃**만 실사용 클래스로 정리한 것.
