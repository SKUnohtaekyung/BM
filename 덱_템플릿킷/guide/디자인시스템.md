> 모든 값은 [`styles/deck.css`](../styles/deck.css)의 `:root` 및 컴포넌트에 구현돼 있습니다. 이 문서는 **왜/언제** 쓰는지의 규칙입니다.

## 2. 타이포그래피

- **폰트**: Pretendard(한글) — CDN 로드. 폴백 `-apple-system, Apple SD Gothic Neo, Noto Sans KR, Malgun Gothic`.
- **전역**: `letter-spacing:-0.02em`, 한글 줄바꿈 `word-break:keep-all`(단어 중간 안 끊김).

| 역할 | class | 크기/굵기 |
|---|---|---|
| 표지 주차 | `.week` | 40 / 800 |
| 표지 한글 타이틀 | `.ko` | 64 / 800, ice |
| 본문 제목 | `.s-title` | 44 / 800 (`.hl` 파랑) |
| 센터 메시지 | `.cm-title` | 52–64 / 800 |
| 리드 | `.s-lead` | 26 / 700 |
| eyebrow(파트라벨) | `.s-eyebrow` | 17 / 700, 코발트 |
| 본문 | `.s-body` | 19 / 1.7 (강조 `strong`→코발트) |
| 캡션·풋 | `.s-foot` | 13 / 600, gray-400 |

**규칙:** 제목 = 결론(1~2줄) · 강조는 키워드 1~2개 · 본문 5줄↑ 분할 · 강의체("~해요/~봅니다") 허용 · 추상 필러("혁신적인 사용자 경험") 금지.

## 3. 공간 · 컴포넌트

- **헤더(모든 흰 슬라이드 고정, 표지·클로징 제외):** 좌 로고 → `SKU LIKELION` → ice 라인 → 우 팀 2줄. 위치는 슬라이드 간 **절대 이동 금지**(브랜드 고정).
- **본문 컬럼** `.s-body-wrap`: `left:64 top:132 width:560`. 세로 가운데는 `.center-v`.
- **풀폭** `.s-full`: `left/right:64 top:118`. 표/그리드가 세로를 채우려면 `.canvas-fill`.
- **번호 원** `.num-circle`: 64px 코발트 단색(원마다 색 바꾸지 않음).
- **강조 바** `.accent-bar`: 120×14 코발트.
- **카드** `.card`: radius 18, 흰/서피스, soft shadow.
- **콜아웃** `.callout(.blue/.green/.orange/.yellow/.red)`: 의미별 색. 오렌지/레드는 주의·오답에만.
- **표** `table.t`: 코발트 헤더 + 제브라. 5열 조밀형은 `.tbl.model`.

**접근성:** 색만으로 의미 전달 금지 → 아이콘/라벨 병행. PDF에서 색 이모지가 깨질 수 있어 **모노크롬 심볼**(◆ ★ ◎ ※ ▲ ▷ ↻ ✓ ↓) 권장.
