# 강의덱 제작 시스템

SKU LIKELION 강의덱을 **같은 느낌으로** 반복 제작하기 위한 저장소입니다.
구조는 **공유 템플릿킷 1벌 + 주제별 세션 폴더 N개**입니다.

```
├─ 덱_템플릿킷/          ← 공유 · 모든 세션이 재사용 (디자인 시스템·레이아웃·이미지 프롬프트)
│  ├─ 00_레이아웃-선택가이드.md
│  ├─ styles/deck.css
│  ├─ starter/deck-template.html
│  ├─ layouts/카탈로그.html
│  ├─ images/공통이미지프롬프트.md
│  ├─ guide/디자인시스템.md
│  ├─ img/                ← 카탈로그·스타터 데모 이미지(자체 보유 → 킷 독립형)
│  └─ reference/          ← 원본 디자인 레퍼런스 (design.md · ppt_layout_reference.md · image_generation_prompts.md)
│
└─ 세션/
   └─ BM_수익모델/        ← 세션 #1 (BM 비즈니스 모델 & 수익 모델)
      ├─ BM_수익모델_강의덱.html · _배포.html   ← 덱(개발·배포)
      ├─ img/ · dist/ · _redirects              ← 이미지·배포
      ├─ 비즈니스모델_수익모델_정리본.md          ← 정본 콘텐츠(원천)
      ├─ _컨텍스트_타겟과커리큘럼.md · 정리본_검증리포트.md · 강의진행안_run-of-show.md
      ├─ business_revenue_model_summary.html
      └─ README.md         ← 이 세션의 상세 안내
```

## 새 세션(새 주제) 만드는 법

1. `세션/<새주제>/` 폴더를 만든다.
2. `덱_템플릿킷/starter/deck-template.html` 를 그 안으로 복사하고, 옆에 `img/`(+`img/slides/`) 폴더를 둔다. (이미지 경로를 `img/` 로 맞춤)
3. **콘텐츠 먼저** — 정본 `.md`(원천) → 필요 시 검증 → 진행안. 슬라이드는 콘텐츠에서 나온다.
4. **덱 조립** — [`00_레이아웃-선택가이드.md`](덱_템플릿킷/00_레이아웃-선택가이드.md)로 상황별 레이아웃을 고르고 [`카탈로그.html`](덱_템플릿킷/layouts/카탈로그.html)에서 `<section>`을 복사해 채운다.
5. **이미지** — [`공통이미지프롬프트.md`](덱_템플릿킷/images/공통이미지프롬프트.md)로 clay v2 3D 에셋 생성.
6. 이 파일의 **세션 목록**에 한 줄 추가.

> 디자인은 `덱_템플릿킷/`에서 한 번만 관리 → 모든 세션이 자동으로 같은 느낌을 상속합니다.
> 디자인 규칙을 바꾸고 싶으면 `덱_템플릿킷/styles/deck.css` 한 곳만 고치세요.
