# BM — 비즈니스 모델 & 수익 모델 (멋쟁이사자처럼 UXUI 16주차)

멋쟁이사자처럼(LIKELION) UXUI 트랙 **16주차 “비즈니스 모델(BM)” 세션**의 강의 자료와 제작 시스템을 모은 저장소입니다.

> **한 줄 목표** — “우리가 만든 서비스, 이거 어떻게 돈 벌어요?”라는 질문에 **기획자로서 답할 수 있게 되기.**

---

## 누구를 위한 세션인가

| 항목 | 내용 |
|---|---|
| **대상** | 기획을 막 배우는 아기사자 (대학 1~3학년, 비즈니스 비전공 전제) |
| **시간** | 60~80분 · 토론식 |
| **형식** | 3명씩 2팀 · 팀 실습(린캔버스) 중심 |
| **위치** | 해커톤(19주차) 직전 “비즈니스 관점 장착” 세션 |

학생들은 BM 세션 전까지 **역기획·페르소나·문제정의·MVP·IA/플로우·화면설계·상태설계·아이디어톤**을 이미 배웠습니다. BM은 그 위에 **“어떻게 지속되는가(돈·비용)”**를 얹는 자료로 포지셔닝합니다.

## 사용법

- **웹으로 보기**: `business_revenue_model_summary.html`을 브라우저로 열기(인쇄 시 A4 출력 최적화됨).
- **자료를 수정할 때**: 반드시 [`_컨텍스트_타겟과커리큘럼.md`](_컨텍스트_타겟과커리큘럼.md)를 먼저 읽어 **눈높이·용어·커리큘럼 연결**을 맞춥니다. 이미 배운 개념은 재설명하지 말고 “연결”합니다.
- **HTML ↔ 정리본 동기화**: 정리본(`.md`)이 원천입니다. 내용을 바꾸면 HTML도 같은 내용으로 맞춰 주세요.
- **HTML 웹덱을 만들 때**: 공유 [`덱_템플릿킷/`](../../덱_템플릿킷/README.md)을 씁니다 — `00_레이아웃-선택가이드.md`(상황→레이아웃) → `layouts/카탈로그.html`(레이아웃 복사) → `images/공통이미지프롬프트.md`(에셋). 원본 규칙은 `reference/`의 `design.md`·`image_generation_prompts.md`.
- **발표할 때**: [`BM_수익모델_강의덱.html`](BM_수익모델_강의덱.html)을 브라우저로 열고 방향키로 넘깁니다. 학생 배포·오프라인 공유에는 [`BM_수익모델_강의덱_배포.html`](BM_수익모델_강의덱_배포.html)을 사용하세요.
