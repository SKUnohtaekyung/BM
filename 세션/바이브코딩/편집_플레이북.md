# 바이브코딩 덱 편집 플레이북 (에이전트 참조용)

> 목적: 사용자(기획/디자인·발표자)가 프리뷰에서 요소를 골라 번호로 수정 요청한다.
> 이 문서는 그 요청을 **빠르고 정확히, 매번 지적받지 않아도** 반영하기 위한 기준이다.
> 새 편집 턴 시작 전에 이 문서와 `.claude/skills/likelion-deck/references/visual-first.md`를 먼저 본다.

---

## 1. 작업 루프 (사용자가 일하는 방식)
- 사용자가 **Claude Preview에서 DOM 요소를 클릭** → `<launch-selected-element>`로 tag·class·path·html·siblings가 넘어온다.
- 요청은 **선택한 요소 순서대로 넘버링**으로 온다. 번호 N = 그 요소(또는 그 슬라이드) 수정.
- **프리뷰 직접 실행/스크린샷 금지** — 사용자가 직접 본다. 검증은 grep/Read/`preview_eval` 측정 또는 서브에이전트 리뷰로만.

## 2. 이 워크플로우를 받쳐주는 Claude 기능
| 기능 | 용도 |
|---|---|
| **Preview 요소 선택 핸드오프** | 사용자가 고른 요소의 html/경로가 그대로 옴 → **그 html을 Edit old_string 앵커로** 안전 치환 |
| **Edit(정확 치환)** | 선택 요소 html을 그대로 써서 오편집 방지 |
| **Grep / Read** | 슬라이드 위치·중복 클래스·전수 확인 |
| **likelion-deck 스킬** | `layouts/카탈로그.html`(레이아웃 라이브러리)·`styles/deck.css`(토큰)·`references/visual-first.md`(정보→도형) |
| **Memory(feedback)** | 반복 지적을 기억해 다음 턴 선반영 (`deck-editing-preferences`) |
| **Sub-agent / Workflow** | 프리뷰 없이 검증할 때 병렬 적대 리뷰 |

## 3. 수정 요청 카테고리 & 처리 규칙 (관찰된 패턴)
| 유형 | 사용자 표현 | 처리 |
|---|---|---|
| 문구/노드 삭제 | "~ 빼", "다 빼", "박스 빼" | 그 노드/문장만 제거 + 레이아웃 재균형 |
| 부호·따옴표 제거 | "'' 빼", "온점 빼" | 텍스트만. 강조는 다른 수단(색·굵기)로 유지 |
| 문구 교체 | "~로 바꾸기", "~ 말고 다르게" | 의미 보존, 지정 문구로 |
| 정보량↑·이미지↓ | "정보량 늘려, 이미지 줄여/구석으로" | 이미지 폭↓·코너 이동, 카드/표 정보 확장 |
| 난이도↓ | "어려워, 쉽게" | 용어 뜻·줄임말·**예시(챗지피티·제미나이)**·비유. 표/박스 크기를 정보량에 맞춤 |
| 슬라이드 병합 | "N,M 합치자" | 중복 제거·핵심만·레이아웃 재판단(내가 결정) |
| 레이아웃 재설계 | "레이아웃 별로/다른걸로", "꽉 채워" | **§4 다른 레이아웃**으로 교체·채움 |
| 없는 것 생성 | "~파일 없어, 슬라이드에 만들어" | 실제 콘텐츠를 슬라이드에 직접 제작 |
| 색·강조 | "글씨 흰색으로" | 해당 요소 색 토큰 조정 |

## 4. ★ 레이아웃 다양성 규칙 (최우선 — 반복 지적됨)
**증상**: 개념 슬라이드가 `center-v`(좌 텍스트+우 hero)·`center-msg`로 쏠려 단조롭다.
**원인**: 범용 레이아웃을 기본값으로 집고, 콘텐츠 모양에 맞는 특수 도형 레이아웃을 덜 썼다.

**규칙**
1. 슬라이드마다 **먼저 정보의 모양**을 판단(관계/대비/흐름/포함/매핑/격자/분해/지표) → `visual-first.md` 표로 레이아웃 선택.
2. **같은 레이아웃 2연속 금지.** 특히 center-v / center-msg 연속 금지. 파트 안에서 레이아웃이 반복되면 다른 걸로.
3. **미사용/저사용 레이아웃 우선 소진**: `venn-slide`(포함), `reverse-slide`(4카드 분해 보드), `risk-slide`(가정→위험→검증), `metric-slide`(지표 카드행), `price-slide`(2카드 상세), `remind-slide`(기울인 사진 2장), `compare-slide`(2패널 대비), `map-slide`(A→B), `flow-slide`(스텝).
4. **"좌 텍스트 + 우 이미지" 고정을 깨라**: 이미지를 **하단 배경**·상단 띠·카드 뒤 배경·표 거터·per-card 아이콘으로. 이미지 없이 도형만으로도 OK.
5. 카탈로그의 **검증된 `<section>`을 복사**해 쓰면 프리뷰 없이도 깨질 위험이 낮다(새 CSS 최소화).
6. 조립 후 **레이아웃 분포를 세어** 한 클래스가 과반이면 재분배.
