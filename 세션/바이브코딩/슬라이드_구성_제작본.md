## D. 이미지 SUBJECT 시트 (make_prompt_sheet.py 뒤 붙여넣기용)

> `make_prompt_sheet.py`가 슬롯을 스캔해 `이미지프롬프트.md`를 만들면, 각 항목 `SUBJECT`에 아래를 넣는다. **경고 슬라이드(10)만** 블록2에 오렌지 악센트 1점 추가. 캐릭터는 faceless.

```
s01 cover-tiles      : 문서 카드들이 작동하는 앱 화면 타일로 변해 흩어지는 몽타주
s02 doc-to-screen    : 문서 1장 → 화살표 → 켜진 폰/웹 화면으로 변신 + 가리키는 작은 캐릭터
s05 ai-delegation    : 캐릭터가 로봇에게 두꺼운 작업 서류 뭉치를 건넴 + 물음표
s06 prototype-mock   : 캐릭터가 미니어처 화면 모형을 들고 옆에 예시 데이터 카드 3장
s07 llm-vs-agent     : (좌)말풍선 하나 든 캐릭터 vs (우)여러 도구 쥔 캐릭터, 가운데 대비
s08 answer-vs-act    : 위=말풍선 스피커, 아래=톱니·손 달린 일꾼 로봇 (세로 대비)
s09 term-badge       : 큰 공식 뱃지에 작은 손글씨 별명 스티커가 붙음 (글자 없이 형태만)
s10 agent-acts       : 큰 실행 버튼 위 캐릭터 손가락 + 오렌지 경고 1점  ← WARNING
```
